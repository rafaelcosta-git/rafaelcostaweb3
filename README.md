# Rafael Costa — Developer Portfolio

Personal portfolio website showcasing full-stack, Web3, and AI projects, technical skills, and professional background.

🌐 **Live:** [rafaelcostaweb3.lovable.app](https://rafaelcostaweb3.lovable.app)

---

## Tech Stack

- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite
- **Styling & UI:** Tailwind CSS, shadcn/ui, Radix UI, Lucide Icons
- **Forms & Data:** React Hook Form, Zod, TanStack React Query
- **Testing:** Vitest, Testing Library

---

## Local Development

```bash
git clone https://github.com/rafaelcosta-git/rafaelcostaweb3.git
cd rafaelcostaweb3
npm install
npm run dev
```

Available scripts:
- `npm run dev` — start local dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
- `npm run test` — run Vitest suite
